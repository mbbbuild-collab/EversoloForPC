# EversoloForPC

A Windows companion for **Eversolo** network streamers (developed against a DMP-A8): a now-playing
desktop widget, a full-screen "big screen" for a second monitor, instant library search, and
bit-perfect playback of the same file on your PC's own DAC.

> Unofficial project. Not affiliated with, endorsed by, or supported by Eversolo / Zidoo.
> It talks to the device's local control API on your own network. Use at your own risk.

![icon](assets/icon-256.png)

## Features

- **Widget** — always-on-top corner card: cover, title, artist, album, format, progress,
  previous / play-pause / next. Draggable, remembers its place, double-click for a mini bar.
- **Big screen** — full screen on a monitor of your choice: album sleeve with a spinning record,
  cross-fading covers, drifting blurred background, up-next list, live spectrum.
- **Search** — the whole library (hundreds of thousands of tracks) indexed locally, accent- and
  Turkish-insensitive, with cover thumbnails, format, duration and folder so duplicate copies
  can be told apart. Files that no longer exist on the NAS are flagged instead of played.
- **Listen on this PC** — plays the very file the streamer is playing, straight from the NAS share,
  in sync with the device: ffmpeg decoding, WASAPI **exclusive** output at the file's own sample rate
  (bit-perfect for FLAC / WAV / AIFF / ALAC). DSD (DSF / DFF) is converted with a linear-phase
  low-pass, configurable headroom and a transparent peak limiter.
- **Settings window** — device IP (auto-discovery), monitors, output device, exclusive mode,
  DAC rate limit, DSD gain / filter / limiter, NAS root, ffmpeg path, visual effects.
- **Command line** — `EversoloForPC.exe --playpause | --next | --prev | --local | --big | --settings`
  is forwarded to the running instance (handy for hotkeys or a Stream Deck).

## Requirements

- Windows 10 / 11 x64. The installer is self-contained (no .NET install needed).
- An Eversolo streamer on the same network (control API on port 9529).
- For "Listen on this PC": the music share reachable over SMB from the PC, and
  [ffmpeg](https://ffmpeg.org) — not bundled; the installer can fetch it with
  `winget install Gyan.FFmpeg`, and the app finds it automatically.

## Install

Download `EversoloForPC-Setup-x.y.z.exe` from the Releases page and run it. It installs per user
(no administrator rights). On first start the app scans the local network for the streamer;
you can also type its IP in Settings.

## Build from source

```bash
dotnet build -c Release
```

Installer (needs [Inno Setup 6](https://jrsoftware.org/isinfo.php)):

```bash
dotnet publish -c Release -r win-x64 --self-contained true -o publish
```

```bash
ISCC installer\EversoloForPC.iss
```

The icon is generated by `tools\make-icon.ps1`.

## Keys on the big screen

`/` search · `Space` play / pause · `←` `→` previous / next · `L` listen on this PC ·
`F5` refresh library · `Esc` close

## Data

Settings, the library index, cover thumbnails and logs live in `%AppData%\EversoloForPC`.
Nothing leaves your network.

## Notes for developers

The device API is undocumented; what was learned the hard way is in
[docs/DEVICE-API.md](docs/DEVICE-API.md). Read it before probing the device: some calls stall its
music database for minutes.
